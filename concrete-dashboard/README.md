# 混凝土營運與質量分析看板（合成數據版）

這是一個可直接操作的作品集專案，用來展示預拌混凝土工廠的生產經營、分廠比較、膠材結構與配合比監控分析。

> **保密聲明：網站中的所有數值、廠別、工程類別、配比代碼、趨勢與排名均為合成示例，不代表任何真實企業、項目或生產紀錄。**

## 看板能回答甚麼

- 年度與月度出貨規模如何變化？
- 不同示例分廠的方量、產品結構與膠材單耗有何差異？
- OPC、PFA、GGBS、MSF 的理論需求、採用率和膠材佔比如何？
- 同等級、同工程類別、同坍落度與同膠材體系下，哪些配比值得技術覆核？
- 在沒有強度及逐盤實投資料時，哪些結論不能下？下一步要補甚麼資料？

## 脫敏方法

公開版不是把機密數值乘倍率、加噪音或重新排序。它使用固定種子的獨立生成模型，重新建立 3 個示例年度、4 個示例分廠、5 類工程與匿名配比資料。公開倉庫沒有原始 Excel、真實彙總、真實識別碼或含機密資料的 Git 歷史。

## 使用方式

直接開啟 `index.html`，或使用 GitHub Pages 連結。網站為純靜態頁面，資料保存在 `data.js`，不會連接外部伺服器。

## 分析邊界

材料用量為「配合比單耗 × 合成出貨量」的理論值。沒有實測強度、實際投料、價格、產能、退料或投訴資料，因此不把理論參數解讀為質量合格、實際成本、材料浪費或產能利用率。
