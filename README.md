# 预制外墙装车试排 v0.2（纯静态版）

本目录是完整网站，无需 ChatGPT Sites、Node.js、Python、数据库或服务器端程序。

## 部署

把本目录内的所有文件上传到任意静态托管平台的网站根目录：

- index.html
- styles.css
- engine.js
- app.js

适用于 GitHub Pages、Cloudflare Pages、Netlify、Vercel Static、对象存储静态网站及普通 Web 服务器。

## 本地查看

可直接双击 index.html。若浏览器或企业安全策略限制本地文件，请用任何静态文件服务器打开本目录。

## 数据与依赖

- 所有计算都在访问者的浏览器内完成。
- 没有外部字体、CDN、API、第三方脚本、Cookie、分析代码或网络请求。
- “保存方案”会下载 JSON；“打开方案”只读取用户主动选择的本地 JSON。
- 刷新页面会恢复内置测试数据。

## 计算边界

这是尺寸与重量试排工具。运输架参数、允许倾角、轴荷、支承、绑扎、路线及卸车稳定仍须由项目相关专业人员核实。
