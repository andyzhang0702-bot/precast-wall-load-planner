# 预制外墙装车规划器 · Precast Wall Load Planner

把预制外墙的尺寸、重量与车辆限制转化为可检查的装车方案。输入构件数据后，工具自动分车，并生成俯视和侧视装载示意。

**[在线体验 / Live Demo](https://andyzhang0702-bot.github.io/precast-wall-load-planner/)**

![项目展示图](assets/showcase.png)

## 核心约束

- 单车承重上限：20 t
- 车辆总高上限：4.6 m
- 可用装载长度：9 m / 12 m
- 车架可用宽度：2.5 m
- 两组运输架之间预留约 250 mm 通道
- 每排最多安排 4 件外墙

## 使用方式

1. 输入构件编号、数量、长宽高和单件重量。
2. 选择车辆长度及车架高度。
3. 自动计算分车方案并查看风险提示、车辆清单和装车图。
4. 可保存或重新打开 JSON 方案文件。

## 技术说明

这是纯 HTML / CSS / JavaScript 前端应用，不需要服务器、数据库或 ChatGPT 运行环境。所有计算均在访问者的浏览器内完成，页面不加载外部字体、CDN、API、分析代码或第三方脚本。

## 计算边界

当前版本用于尺寸与重量试排。正式运输前，运输架参数、允许倾角、轴荷、支承、绑扎、路线和卸车稳定仍需由项目相关专业人员核实。
